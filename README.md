# אתר גל עיני - תוכנה חינמית ללא AI

תיקייה זו היא אתר סטטי שאפשר לפתוח ישירות בדפדפן או להעלות בחינם ל-GitHub Pages.

## קבצים

- `index.html` - עמוד הבית.
- `web.html` - עבודה באתר עם מנוע החיפוש.
- `examples.html` - עמוד אוצר הצפנים.
- `ai.html` - כלי עזר מקומי לבניית רשימת מילים לעיון.
- `order.html` - הכנת בקשת חיפוש לפי הזמנה.
- `contact.html` - פניות צור קשר הנשלחות למערכת, עם עותק מקומי לגיבוי.
- `admin.html` - לוח ניהול לפניות, תוכן, העלאות ונתוני האתר.
- `admin-config.js` - הגדרות כניסה והעלאה לניהול.
- `styles.css` - עיצוב האתר.
- קישור הורדה פעיל: `https://neriyado20-lab.github.io/downloads/gal_einai_V483_public_auto_update_setup.exe` - התקנת גל עיני V483 ללא AI.
- עדכון פעיל: `https://neriyado20-lab.github.io/downloads/gal_einai_V483_public_upgrade_setup.exe` - עדכון גל עיני V483 ללא AI.
- `downloads/archive/` - גרסאות ישנות יותר נשמרות לארכיון.
- `archive/` - קבצים ישנים או לא מקושרים שנשמרו לארכיון במקום להימחק.

## הפעלה מקומית

פותחים את `index.html` בדפדפן.

## התקנת תוכנת Windows

קבצי V483 ללא AI נבנים ומפורסמים דרך תיקיית `downloads` באתר:

- תוכנה חינמית: `APP_VERSION = "V483"`, `FREE_SKIP_LIMIT = 0`, `AI_FEATURES_ENABLED = False`.

לוח הניהול נמצא ב-`admin.html`. כאשר Supabase פעיל הוא מציג פניות ונתונים מכל המכשירים
מטבלת `site_submissions`; במקביל נשמר עותק מקומי בדפדפן לגיבוי ולבדיקות.

כניסה זמנית ללוח הניהול:

- קוד ניהול: `gal-einai`
- סיסמה: `770770`

את פרטי הכניסה מחליפים ב-`admin-config.js` באמצעות ערכי SHA-256 חדשים. באתר סטטי ההגנה הזו
מיועדת להסתרה בסיסית ונוחות עבודה, ולא מחליפה הרשאות שרת אמיתיות.

בלוח הניהול יש אזור העלאת קבצים. כאשר Supabase Storage זמין, הקבצים עולים לאחסון המרכזי;
אם החיבור אינו פעיל, הם נשמרים זמנית בדפדפן המנהל באמצעות IndexedDB.

בנוסף יש אזור ניהול תוכן וקישורים: הודעות באתר, גרסאות להורדה, אוצר הצפנים, קישורים שימושיים
והערות מנהל. כאשר החיבור המרכזי פעיל הפריטים נשמרים גם ב-`admin_content`; אפשר לערוך, למחוק
ולייצא אותם לקובץ JSON.

בצפנים מאוצר הצפנים אפשר להגדיר `תאריך יעד לארכוב` בעת העלאה או עריכה. צופן פעיל שתאריך
היעד שלו עבר יוסתר מהאוצר הציבורי, ובכניסת מנהל יעבור אוטומטית לסטטוס ארכיון.
