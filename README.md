# אתר גל עיני

אתר סטטי לגל עיני: דף בית, עבודה באתר, הורדת התוכנה, אזור אישי ואוצר הצפנים.

## קבצים מרכזיים

- `index.html` - עמוד הבית והורדות.
- `web.html` - עבודה באתר עם מנוע החיפוש.
- `examples.html` - אוצר הצפנים והממשק הפנימי לניהול האוצר.
- `examples.js` - טעינת צפנים, סינון, שיתוף, דירוג, תגובות וניהול פנימי.
- `styles.css` - עיצוב האתר.
- `public-version.json` - פרטי הגרסה העדכנית לעדכון האוטומטי.
- `downloads/` - קבצי התקנה ועדכון.

## ניהול אוצר הצפנים

אין יותר דף מנהל נפרד. הניהול נמצא בתוך `examples.html`.

כניסה לניהול מתבצעת במחווה נסתרת: גוררים את כפתור הנושא הקיצוני הראשון אל כפתור הנושא הקיצוני האחרון, או להפך, ואז מזינים סיסמת מנהל.

במצב ניהול אפשר לערוך פרטי צופן, נושא, מלל, קישור, סטטוס, להעביר לארכיון או למחוק רשומה. הארכיון מוצג רק במצב ניהול.

האתר הוא אתר סטטי. פעולות שמירה קבועות נשענות על Supabase והרשאות השרת; שמירה מקומית בדפדפן משמשת רק כגיבוי תצוגה.
